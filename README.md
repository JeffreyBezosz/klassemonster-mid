# Klassemonster · Mid-fi prototype

Een klikbaar prototype voor begrijpend lezen in het eerste middelbaar. Open `index.html` in een browser. De site gebruikt gewone HTML, CSS en JavaScript en heeft geen installatie of build nodig.

- **Leerling** leest teksten over mysterie, natuur en avontuur, oefent met verschillende soorten vragen en krijgt uitleg bij de antwoorden. Afgewerkte opdrachten leveren XP voor het monster op.
- **Leerkracht** bekijkt de klasvoortgang, past het weekdoel aan en kan een opdracht met maximaal acht meerkeuzevragen toevoegen.
- **Ouder** ziet de leesresultaten en het weekdoel van Milan.

Wissel van rol via het profiel bovenaan. De namen en startresultaten zijn voorbeeldgegevens. Nieuwe resultaten, gemaakte opdrachten, klasinstellingen en de leespositie worden lokaal in dezelfde browser bewaard. Er is geen server of account nodig.

Op Vercel werkt dit als statische site met preset **Other**, de hoofdmap als root en een leeg buildcommando.
